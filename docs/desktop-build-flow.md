# Desktop App (Electron) — Step-by-Step Flow

Build order: **fourth**, after the mobile app works (`mobile-build-flow.md`). The desktop app reuses the mobile app's screens via `react-native-web` — you are not rewriting the UI, just wrapping it.

---

## Step 1: Add web support to the existing mobile app

```bash
cd mobile
npx expo install react-native-web react-dom
```

Confirm it works in a regular browser first:
```bash
npx expo start --web
```
If `LoginScreen` → `TaskListScreen` works in a browser tab, Electron will have no trouble with it either — fix any web-specific rendering issues here before adding Electron into the mix.

## Step 2: Create the desktop wrapper project

```bash
cd pharma-task-app
mkdir desktop && cd desktop
npm init -y
npm install electron --save-dev
```

## Step 3: Folder structure

```
desktop/
├── main.js              # Electron entry point — creates the BrowserWindow
├── package.json
└── web-build/            # generated by `expo export:web`, not committed to git
```

## Step 4: Build the Expo web output

```bash
cd ../mobile
npx expo export:web
```
This produces `mobile/web-build/`. Either copy that folder into `desktop/web-build/`, or point `main.js` directly at the `mobile/web-build/index.html` path — copying is simpler to reason about for packaging later.

## Step 5: Point Electron at the build

`desktop/main.js`:
```js
const { app, BrowserWindow } = require('electron');
const path = require('path');

function createWindow() {
  const win = new BrowserWindow({
    width: 1200,
    height: 800,
    webPreferences: { contextIsolation: true },
  });
  win.loadFile(path.join(__dirname, 'web-build/index.html'));
}

app.whenReady().then(createWindow);

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') app.quit();
});
```

## Step 6: Test it

```bash
cd desktop
npx electron .
```

**Done when:** the same login → task list → task detail flow from the mobile app runs inside a native desktop window, hitting your live hosted API.

## Step 7: Package the `.exe`

```bash
npm install electron-builder --save-dev
npx electron-builder --win
```
This produces an installable `.exe` in `desktop/dist/`. Host it on your own site/portal alongside the `.apk` — same "no app store" distribution model.

## Step 8: Auto-update (optional, add once you have real users)

```bash
npm install electron-updater
```
Configure `electron-updater` to check your own release server (a simple static file listing the latest version + download URL is enough — you don't need a full update service). Mirrors the `GET /app/latest-version` check on mobile, so both platforms stay in sync without app-store help.

## Step 9: Write install instructions for clients

`docs/install-instructions.md`:
- Android: enable "install unknown apps" once, then install the `.apk`
- Windows: the `.exe` is unsigned unless you buy a code-signing certificate, so Windows SmartScreen will show a warning the first time — document the "More info → Run anyway" click so it doesn't look broken to a non-technical office user

1. `database-design-flow.md` — control-plane DB + tenant DB template on Neon
2. `backend-build-flow.md` — NestJS API, hosted, tested fully in Postman
3. `mobile-build-flow.md` — Expo app, built against the live API, packaged as `.apk`
